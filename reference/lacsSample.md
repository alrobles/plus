# Data frame with 600 abstracts. Each abstract belongs to one of both classes, positive and unknown. Abstracts from parasite class are from ZOVER and GMPD database. Abstracs from unknown class are random abstracts retrived from crossref.

Data frame with 600 abstracts. Each abstract belongs to one of both
classes, positive and unknown. Abstracts from parasite class are from
ZOVER and GMPD database. Abstracs from unknown class are random
abstracts retrived from crossref.

## Usage

``` r
data(lacsSample)
```

## Format

An object of class `"data.frame"`;

## Examples

``` r
data(lacsSample)
```
